# Amit Singh | Software Developer Portfolio

A modern, responsive personal portfolio showcasing my skills, projects, and experience as a Software Developer.

## 🚀 Tech Stack
- Next.js 16
- React 19
- TypeScript
- Tailwind CSS v4
- Framer Motion
- Lucide React

## ✨ Features
- Modern Neo-Brutalist / Editorial UI
- Dark and Light Theme
- Responsive Design
- Smooth Animations
- Interactive AI Chatbot
- Projects Showcase
- Skills and About Section
- Contact Section

## 🛠️ Getting Started

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
cd my-portfolio
```

Install dependencies:

```bash
npm install
```

Configure your environment variables in `.env.local`.

Run development server:

```bash
npm run dev
```

Open http://localhost:3000.

## 📦 Production Build

```bash
npm run build
npm start
```

## 🔐 Environment Variables

Add your required API keys to `.env.local`. Never commit secret keys to GitHub.
